# HTML & CSS Practice

This repository contains two beginner HTML and CSS projects.

## Projects

### 1. Business Card

A simple personal business card containing:

* Name and job title
* Contact information
* Social links
* Skills
* Contact form

**Files:**

* `business-card.html`
* `style.css`

### 2. Pricing Cards

A pricing page with three plans:

* Free — KES 0/month
* Pro — KES 1,500/month
* Enterprise — KES 5,000/month

The cards use Flexbox and are responsive on mobile devices.

**Files:**

* `pricing.html`
* `pricing.css`

## Technologies

* HTML5
* CSS3
* Flexbox
* Media Queries
